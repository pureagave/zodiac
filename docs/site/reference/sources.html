Source documents

This site is a conversion, not a rewrite. Every page states which repository Markdown it came from. This table is the map in the other direction — from source file to the page that carries it — so you can always get back to the original.

Precedence

Where two sources disagreed, the newer or corrected one was used and the disagreement noted in place rather than silently resolved. Where a source marks something unverified, operator-recorded, outstanding, or a known bug, that framing is carried through verbatim in intent. Nothing here invents a feature, a number, a file path, or console output.

What is not represented here

Deliberately out of scope
  • SYNC.md's 3,000-line history. It is a chronological log, not reference material, and reproducing it would duplicate the corrected state that README.md and ARCHITECTURE.md already carry. It is cited where a decision's why lives only there.
  • The full audit evidence. The three audits — the 2026-08-09 20-finding review and the two 2026-08-13 fleet-wide passes — are summarised on Status; the finding-by-finding detail is best read in the originals with the code open.
  • jetson/sensor-pod-assembly.svg. The assembly diagram is a repository asset and is referenced rather than reproduced, because it could not be regenerated faithfully.
  • Low-level backlog items in tasks/open.md that are pure code hygiene (file splits, KDoc notes, lint config) rather than facts about the system.
